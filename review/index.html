1Inert control

JD avatar

Editor header and project library · top-right circular JD button

What is wrong

Decision options

Remove the button behavior (keep decorative initials), or implement a workspace/profile menu.

Evidence

Browser-checked in the audit; no dialog or navigation appeared.

3Broken action

Unlock layer

Design → Layers · closed padlock beside a layer

What is wrong

After locking a layer, clicking its Unlock layer button leaves it locked. The store refuses updates to already locked elements. The separate Lock / unlock command is a workaround.

Decision options

Fix unlocking through the Layers panel.

Evidence

Browser-reproduced during capture: the Unlock layer button remained after activation.

5Ineffective option

Image mask: none / roundRect

Select an image → Design → Style → Mask

What is wrong

Both none and roundRect use the same corner radius, so toggling between them does not remove rounded corners. Ellipse has distinct behavior.

Decision options

Make none remove clipping/rounded corners, or simplify the options.

Evidence

Source-traced; screenshot shows the image Mask selector.

Source references

frontend/src/features/editor/PropertiesPanel.tsx

frontend/src/features/renderer/SlideRenderer.tsx

6Ineffective option

Shape image fill: tile

Select a shape → Design → Style → Fill type: image → Fit

What is wrong

For shapes, tile follows the cover rendering path rather than repeating the image. Slide-background tiling has a working implementation.

Decision options

Implement shape tiling, or remove tile only from shape fills.

Evidence

Source-traced; screenshot shows where to choose Fit (currently cover).

Source references

frontend/src/features/editor/PropertyFields.tsx

frontend/src/features/renderer/SlideRenderer.tsx

7Applicability defect

Unsupported chart toggles

Select a chart → Design → Style · Grid, Values, stacked

What is wrong

Values has no effect for scatter. Stacked has no effect for line, scatter, pie, or donut. Grid has no effect for pie/donut. Unsupported controls remain enabled.

Decision options

Hide or disable unsupported toggles by chart type, or implement their behavior.

Evidence

Source-traced; screenshot shows a scatter chart inspector with these controls available.

Source references

frontend/src/features/editor/PropertiesPanel.tsx

frontend/src/features/renderer/ChartRenderer.tsx

8Applicability defect

Flip commands on unsupported elements

Select text, a line, table, or chart → Arrange → Flip horizontally / vertically

What is wrong

The commands are enabled for these selections, but the implementation only flips shapes and images.

Decision options

Disable for unsupported selections, or implement flipping for those types.

Evidence

Source-traced; screenshot shows enabled flip commands with text selected.

Source references

frontend/src/features/commands/registry.ts

frontend/src/store/editor.ts

9Accessibility defect

Keyboard access to Import

Project library → Import · beside the search field

What is wrong

Mouse import is implemented. Keyboard users cannot focus the Import label or its hidden file input to open the picker.

Decision options

Use a keyboard-accessible button connected to the file picker.

Evidence

Browser DOM checked in the audit: file input hidden; label not keyboard-focusable.
